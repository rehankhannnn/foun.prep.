Preparation roadmap

The plan gives you three jobs: finish the syllabus, revise it, then test it.

Phase 1 — Build the base

27 Sep → 25 Oct

Complete the first pass through the high-weight chapters. Learn concepts and immediately solve basic questions.

  • 2 study blocks/day
  • Prioritise 20–30% modules
  • Make a formula/section notebook

Phase 2 — Finish + revise

26 Oct → 22 Nov

Finish every remaining module, then start active recall and mixed question practice.

  • 3 focused blocks/day where possible
  • Daily 20–30 min revision
  • Weekly mini-test

Phase 3 — Exam mode

23 Nov → 12 Dec

No new rabbit holes. Rotate papers, solve timed mocks, analyse mistakes and revise weak modules.

  • Timed 60-minute practice
  • Past/mock questions
  • Final 3-day light revision
